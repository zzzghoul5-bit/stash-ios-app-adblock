# 上游锁定

`upstreams.lock.json` 记录每个行为参考的固定提交、许可证、用途、Git blob SHA-1 和原始内容 SHA-256。

运行：

```powershell
npm run check:updates
```

工具只比较最新 release/branch 和受监控文件，不下载到项目、不改锁定文件、不替换脚本，也不发布。检测到变化时退出码为 `2`，维护者需要：

1. 阅读目标文件 diff；
2. 确认变化仍只涉及广告；
3. 排除账号、登录、支付、订单和共享业务接口；
4. 更新或新增脱敏 fixture；
5. 执行全部测试；
6. 手工更新固定提交和校验值。

上游仓库普通提交变化但受监控文件未变化时，不要求升级。
